# CNI Open Source Starter 🌱

Welcome to the **Cloud Native Ilorin Open Source Starter**.

If you've ever wanted to contribute to open source but didn't know where to start, you're in the right place.

You don't need to be a developer.
You don't need to know Git.
You don't need to have contributed to an open-source project before.

**We'll start from the basics and learn together.**

---

## 🌍 Open Source Is For Everyone

Open source isn't only for people who write code.

Projects need people with different skills, backgrounds and experiences.

You can contribute if you're a:

* 👨🏾‍💻 Developer
* 🎨 UI/UX Designer
* 📦 Product Manager
* 🔐 Cybersecurity professional
* ✍🏾 Writer
* 🧪 Tester / QA
* 🌐 Translator
* 📊 Data or Analytics person
* 📢 Community builder
* 🎨 Graphic Designer
* 📚 Student or learner
* 🗣️ Technical communicator

And many more.

You could be a frontend developer, backend developer, DevOps engineer, designer, product person, cybersecurity professional, Arabist, writer, researcher, or someone who is simply curious and willing to learn.

**There is a place for your skills in open source.**

Open-source projects need people who can build, design, test, document, translate, research, communicate, organize and solve problems.

---

## 🚀 What You'll Learn

We'll take things one step at a time.

You'll learn:

* What open source actually means
* How people contribute to open-source projects
* What Git and GitHub are
* How to find projects you can contribute to
* How to fork a repository
* How to clone a project
* How to create a branch
* How to make changes
* How to commit your work
* How to push your changes
* How to create a Pull Request
* How to respond to feedback
* How to find your next open-source project

You don't need to learn everything at once.

**Start where you are and move at your own pace.**

---

## 🛠️ You Don't Have to Code

There are many ways to contribute to open source.

You can:

* Fix documentation
* Write or improve tutorials
* Translate content
* Design interfaces
* Test features
* Report bugs
* Improve user experience
* Help with community activities
* Research and share useful information
* Review documentation
* Write code
* And much more

Coding is one way to contribute — **not the only way.**

---

## 🧭 How This Works

This project is designed to be hands-on.

Instead of only reading about open source, you'll actually make a contribution.

We'll start with small tasks and gradually introduce you to the tools and processes used by real open-source projects.

The journey looks something like this:

```text
Curious
   ↓
Learn the basics
   ↓
Try something small
   ↓
Make your first contribution
   ↓
Get feedback
   ↓
Learn from the experience
   ↓
Contribute to real projects
```

Your first contribution doesn't have to be complicated.

It could be fixing a typo, improving a sentence, adding documentation, sharing a useful resource, or eventually writing code.

**Start small.**
